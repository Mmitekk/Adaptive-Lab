### Что сделано
- Создан самостоятельный проект Adaptive Lab, русский светлый монохромный интерфейс с левой навигацией, настройкой устройств, отчётами и экраном предпросмотра.
- Проверки viewport, горизонтального переполнения, текста меньше 12 px, целей нажатия 24/44 px, запрета zoom, Flash/Silverlight/applet, переполненных изображений, HTTP-ответа и ошибок ресурсов.
- Режим одного экрана либо 4–5 экранов: выбранный, 320, 375, 768, 1440 CSS px с дедупликацией ширин. Пресеты iPhone/Pixel/iPad/desktop задают размер, не обещают реальный Safari.
- Полноразмерные цветные снимки ограничены 10 000 px высоты и 4096 px ширины; предпросмотр сохраняет геометрию выбранного viewport и горизонтальное переполнение. Масштаб, отдельный большой просмотр, PNG, подсветка найденных DOM-элементов.
- Рекомендации и CSS-селекторы, список сетевых/JS-ошибок, сравнение снимков, локальная история 20 отчётов с поиском и удалением, HTML/JSON-экспорт. HTML можно открыть и распечатать средствами браузера.
- Прогресс, отмена, восстановление активной задачи при обновлении страницы, одна проверка одновременно, общий лимит 4 минуты.
- Изолированные временные контексты Chrome с sandbox, без профилей пользователя. Только GET/HEAD, блокировка WebSocket/service workers и частных сетей, повторная DNS-проверка и закрепление IP каждого прокси-соединения.
- Сервер закрыт для внешних origin, защищён Host/custom-header проверками, доступен только loopback; безопасно пропускает занятые порты. Фоновый запуск одним файлом.

### Решения и допущения
- Снимки вместо iframe дают предпросмотр страниц с X-Frame-Options; ссылки на снимке намеренно не интерактивны, браузер не нажимает формы/баннеры.
- Формула оценки явно описана в notes: 100 минус взвешенные штрафы; fail — полный вес, warning — половина. Веса 20/20/10/15/5/10/10/7/3. Это не баллы Яндекса.
- Основные открытые источники: https://yandex.ru/support/webmaster/ru/recommendations/mobile-site и https://yandex.ru/support/webmaster/ru/diagnosis/mobile. Авторизованный кабинет не копировался.
- DNS Windows имеет особенности stub/VPN; fallback идёт через системный резолвер обеих семейств с той же валидацией всех адресов, без unchecked connect.
- Обнаруженные браузерным тестом переполнения на 320 px исправлены: min-width:0 для колонок, горизонтальная прокрутка только внутри полосы устройств.

### Открытые вопросы и риски
- Не гарантируется совпадение с Яндексом, реальным Safari, Core Web Vitals или WCAG. Проверяется конкретная страница и состояние после DOMContentLoaded + 1,2 секунды, не весь сайт.
- Не проверяется внутреннее содержимое iframe/Shadow DOM, полнота контента после прокрутки, реальный телефон, клавиатура, интерактивные меню/формы и авторизованные страницы. CAPTCHA не обходится.
- Формы/POST, service workers, WebSocket и private network заблокированы, поэтому некоторые SPA могут отображаться неполно. HTTPS-сертификаты не игнорируются.
- Screenshot и HTML/JSON-экспорт протестированы; фактическая печать на принтере/PDF и двойной клик .cmd через оболочку Windows не выполнялись, underlying node start.js проверен.
